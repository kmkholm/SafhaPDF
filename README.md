# صفحة PDF — Safha PDF

**قارئ PDF أصلي لأندرويد بلا إعلانات وبلا إذن إنترنت، مع ماسح مستندات وأدوات تحرير كاملة.**
A native, ad-free Android PDF reader with **no internet permission**, a CamScanner-style document scanner, and a full PDF toolbox.

تطوير وبرمجة: **د. محمد توفيق** · Developed by **Dr. Mohammed Tawfik** · ORCID [0009-0004-7622-5991](https://orcid.org/0009-0004-7622-5991)

## الميزات · Features

**القراءة**
- تمرير عمودي أو صفحة صفحة (مع تقليب من اليمين لليسار للكتب العربية)، تكبير بإصبعين أو بالنقر المزدوج مع إعادة رسم حادة.
- وضع ليلي يحافظ على ألوان الصور، وورقي، ورمادي؛ إبقاء الشاشة مضاءة، ملء الشاشة، تمرير تلقائي، قفل التدوير.
- بحث يتجاهل التشكيل وأشكال الهمزة، الفهرس، مصغّرات الصفحات، العلامات المرجعية، الروابط الداخلية والخارجية.
- تحديد النص: نسخ، تظليل، تسطير، شطب، ملاحظة، ترجمة، قراءة صوتية.
- تعليق بالقلم والملاحظات والتوقيع المرسوم، وحفظها داخل ملف PDF كتعليقات حقيقية.
- قراءة صوتية للصفحات (عربي/إنجليزي)، طباعة، مشاركة، الملفات المحمية بكلمة مرور.
- يظهر في «فتح باستخدام» ويمكن جعله القارئ الافتراضي؛ والملفات الواردة من واتساب والبريد تُحفظ داخله فتبقى قابلة للفتح.

**ماسح المستندات** (مثل CamScanner)
- كاميرا بكشف حي لحواف الورقة والتقاط تلقائي، أو استيراد من المعرض، أو ماسح Google الذكي إن توفر.
- قصّ بالزوايا مع مكبّر، تصحيح الميلان، فلاتر: سحري (تبييض الورق وإزالة الظل)، رمادي، أبيض وأسود، فاتح.
- عدة صفحات، ترتيب وحذف وتدوير، ثم حفظ PDF بحجم A4 أو Letter.

**الأدوات**
- PDF مصوّر ← نص (OCR عربي وإنجليزي دون إنترنت)، دمج، تقسيم، استخراج صفحات، ترتيب الصفحات، صور ← PDF، ضغط، حماية بكلمة مرور (AES-256) وإزالتها، ترقيم الصفحات، علامة مائية بأي لغة، PDF ← صور، PDF ← نص.

**الخصوصية**
- لا يوجد إذن إنترنت إطلاقاً (مُزال من البيان حتى لو أضافته مكتبة)، فلا إعلانات ولا تتبّع، ولا يخرج أي ملف من الجهاز.

## البناء · Build

```bash
cd android
./gradlew assembleRelease
```
Kotlin + Jetpack Compose · compileSdk 36 · minSdk 26.
